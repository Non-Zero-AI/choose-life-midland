# Choose Life Midland

A responsive landing page for Midland, Odessa, and the greater Permian Basin, with compassionate pregnancy and end-of-life conversation messaging.

Website: https://chooselifemidland.com/

Call to action: **432-695-6955**

## Editing and publishing

The site uses plain HTML and CSS. Edit `index.html` for content and `styles.css` for styling. Keep images and the favicon in `assets/`. No package installation, JavaScript, or build step is required.

GitHub Pages publishes the root of the `main` branch. Changes pushed to `main` are published automatically. `CNAME` sets the custom domain, and `.nojekyll` preserves the static files without Jekyll processing.

To preview locally, run `python3 -m http.server 4321` in this directory and open http://localhost:4321/.

## Assets and fonts

The hero photograph is AI-generated illustrative imagery. It does not depict actual staff or clients. The logo and landscape illustration are SVG. Google Fonts supplies Lora and DM Sans, with Georgia and Arial as local fallbacks.

The page has no forms, analytics, or personal-data collection code.
